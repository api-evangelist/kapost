# Kapost

> Kapost is a content operations platform (now part of Upland Software) for B2B marketing teams to plan, produce, distribute, and analyze content across the customer journey. It exposes a versioned REST Content API (67 documented operations across content, ideas, initiatives, tasks, comments, reminders, visibility, custom fields, users, memberships and insights) secured with HTTP Basic authentication using a per-user API token, returns JSON, and adds three outbound integration surfaces: content webhooks, a generic HTTP publish destination, and an XML-RPC (MetaWeblog subset) CMS interface.

## How to call it
- Base URL is per-tenant and templated: `https://{instance}.kapost.com/api/v1/{resource}` — there is no shared API host (`api.kapost.com/api/v1/content` returns 404).
- Auth: HTTP Basic. Put the API token in the username field and any value (conventionally `x`) in the password field. `curl -u "token:x" "https://your_instance.kapost.com/api/v1/content"`
- Get a token from the API Token section of your edit-profile page inside your Kapost instance.
- Responses are JSON, wrapped as `{ "response": [...], "count": N, "pagination": { previous, next, current, per_page, count, pages } }`.
- Paginate with `page` and `per_page`. Shape the payload with `detail=basic|full` or with `columns[]=...`.
- No idempotency keys, no documented rate limits, no documented error catalog, no OpenAPI specification.

## APIs
- [Kapost Developer Portal](https://developer.kapost.com/): Home of the Content REST API, with a live "Try it" API playground covering every endpoint.
- [API Getting Started](https://developer.kapost.com/api-getting-started): Base URL, HTTP Basic auth (token:x), JSON responses, uri-path versioning (/api/v1/).
- [Content API Responses](https://developer.kapost.com/content-api-responses): basic / full / dynamic response levels and the full content property tables.
- [Custom Field Mappings](https://developer.kapost.com/custom-field-mappings): Mapping Kapost custom field values onto an external system's values via the Destinations API.
- [Webhooks](https://developer.kapost.com/webhooks): Outbound content webhooks (create/update/publish/delete).
- [HTTP Destination](https://developer.kapost.com/http-destination): Generic HTTP publish destination (auth/publish/republish actions, SHA1/SHA256 signatures).
- [XML-RPC](https://developer.kapost.com/xmlrpc-docs): MetaWeblog-subset method reference for pushing content into a CMS.
- [XML-RPC Files](https://developer.kapost.com/xmlrpc-files): File-push methods (kapost.newFile).
- [Gallery Picker](https://developer.kapost.com/gallery-picker): Embeddable JS file picker over the Kapost Gallery.
- [WordPress Plugin](https://developer.kapost.com/wordpress-plugin): Kapost Byline plugin integration docs.
