# Kapost

> Kapost is a content operations platform (now part of Upland Software) for B2B marketing teams to plan, produce, distribute, and analyze content across the customer journey. It exposes a versioned REST Content API secured with HTTP Basic authentication (API token as username), returns JSON, and supports content webhooks, an XML-RPC interface, and a first-party WordPress plugin.

## APIs
- [Kapost Developer Portal](https://developer.kapost.com/): Home of the Content REST API, webhooks, and XML-RPC docs.
- [API Getting Started](https://developer.kapost.com/api-getting-started): Base URL, HTTP Basic auth (token:x), JSON responses, uri-path versioning (/api/v1/).
- [Content API Responses](https://developer.kapost.com/content-api-responses): Content resource response reference.
- [Webhooks](https://developer.kapost.com/webhooks): Outbound content webhooks (create/update/publish/delete).
- [XML-RPC](https://developer.kapost.com/xmlrpc-docs): XML-RPC method reference.
- [WordPress Plugin](https://developer.kapost.com/wordpress-plugin): Kapost Byline plugin integration docs.
